# ein Gedankensprung — One-Pager

A self-contained one-page site for Mag. Lisa Kuhn's project management, coaching, and consulting practice ([eingedankensprung.at](https://www.eingedankensprung.at)).

**Live site:** https://einseitensprung.github.io/ein-gedankensprung/

## About

Single `index.html` file — no build step, no dependencies. All fonts (Bricolage Grotesque, Newsreader, IBM Plex Mono) are embedded as base64 `@font-face` data URIs, so the page renders identically everywhere without external requests.

The design centers on the "Gedankensprung" (leap of thought) concept: a dotted long-jump trajectory with measurement ticks runs through the hero and closing sections, visually tying the brand name to the precision/KPI focus of the consulting work.

## Local development

Just open `index.html` in a browser — no server or build tools required.

## Deployment

Hosted via GitHub Pages, served directly from the `main` branch root.
